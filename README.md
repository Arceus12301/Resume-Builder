# Resume-Builder (ResumeCraft)

A clean, modern, zero-slop Online Resume Builder built with React 19, Tailwind CSS v4, Vite, and Phosphor Icons. Designed specifically for college students, freshers, and developers to create professional, ATS-friendly resumes in minutes.

## Features

- **Blank-by-default canvas**: Start from scratch or load clean sample profiles with 1-click.
- **Photo Upload Support**: Upload, preview, and delete custom headshot profile photos.
- **4 Clean Resume Templates**:
  - **Modern Clean (Swiss)**: Structured typography, high hierarchy, professional layout.
  - **Tech Linear**: Developer-focused monospace identity and compact project cards.
  - **Classic Academic (Executive)**: Traditional serif formatting ideal for academic and formal roles.
  - **Two-Column (Studio)**: Balanced sidebar for skills, links, and credentials.
- **Pixel-Perfect A4 Printing & PDF Export**: Isolated print stylesheet hides all UI controls, scrollbars, and browser clutter for clean single-page PDF output.
- **Privacy First & Local Persistence**: Auto-saves locally in your browser with zero logins and zero remote trackers.
- **JSON Import / Export**: Download your resume state anytime as `.json` and restore it with one click.

## Tech Stack

- **Framework**: React 19
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: `@phosphor-icons/react`
- **Linting**: Oxlint

## Local Development

```bash
# Clone the repository
git clone https://github.com/Arceus12301/Resume-Builder.git

# Enter project directory
cd Resume-Builder

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
