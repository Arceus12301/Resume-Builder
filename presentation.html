How ResumeCraft Works

An intuitive, privacy-first web application engineered from scratch using modern web standards to convert structured input into clean, ATS-compliant, print-ready resumes in real time.

01

Zero Backend Needed

Runs 100% inside the browser. No databases, login walls, or third-party data tracking.

02

Synchronous State Engine

Every keystroke in the form editor immediately propagates to the live A4 preview canvas.

03

Pixel-Perfect Print Pipeline

Dedicated print stylesheet eliminates all UI buttons, sidebars, and transforms for vector PDF output.

Slide 4 · Media Handling

In-Browser Profile Photo Processing

Zero backend file uploads; purely browser-native FileReader and Base64.

Step 1: Selection

User selects a local JPG, PNG, or WebP photo via file input (< 2MB limit check).

Step 2: FileReader API

HTML5 readAsDataURL() converts image binary directly into a Base64 data string.

Step 3: State Sync

Stored in personalInfo.photoUrl, enabling instant preview, saving, and export.

Key Advantage: Since the photo is encoded directly within the resume JSON object, your saved file remains completely self-contained and loads on any computer without broken image links.
Slide 5 · Print Engine

Flawless Print & PDF Generation

Bypassing heavy third-party PDF libraries using native browser print rules.

Screen Mode (Editor)

  • Split 2-column layout (Form Editor left, Canvas right).
  • Interactive zoom controls (50% to 120%) using CSS scale transforms.
  • Dark theme container with responsive mobile tabs.

Print Mode (@media print)

  • Form editor, navbar, footer, and buttons are hidden via display: none !important.
  • Scale transforms reset to transform: none to prevent cutoffs.
  • Standard A4 portrait geometry with zero margins for vector quality PDF saves.
